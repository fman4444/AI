# PRD — 주 4.5일제 근무 현황 점검 웹앱

> 팀 PRD 인터뷰(코어) 결과 · `[가정]`은 조원이 정하지 않아 세션이 채운 내용이며 `docs/team_decisions.md`에도 있습니다.

## 1. 프로젝트 개요

- 해결하려는 문제: 매주 부서별로 4.5일제 평가기준 충족 여부를 검토하는 과정에서, 근태를 제각각 받아 모으고, 평가기준에 대조해 계산하고, 기준이 바뀌거나 예외가 생길 때마다 다시 따지는 일이 번거롭다.
- 배경: 4.5일제가 새로 시행돼 매주 충족 여부를 확인해야 하는데, 부서와 인원이 많아 수작업으로는 시간이 모자란다.
- 기대 변화: 근태 수합 + 수작업 계산 + 기준 변경 시 재계산 → 부서원이 직접 근태를 입력하고, 평가기준 대비 충족 여부가 부서별로 자동 계산되어 보이며, 사람은 결과 확인과 확정에만 시간을 쓴다.

## 2. 사용자 분석

- 주 사용자: 부서원(약 50명)과 검토 담당자가 비슷한 비중으로 쓴다. 부서원은 개인 근태를 입력하고, 검토 담당자는 충족 여부를 검토한다. 검토 담당자 수는 정하지 않음 — 이번 시연은 검토 담당자 한 사람 기준(조 결정).
- 사용 맥락: 매주 목요일 퇴근 전까지 부서원이 금요일 하루의 근태를 입력 → 금요일 근태를 평가기준에 따라 분류해 4.5일제 실적 달성 여부를 체크한다.
- 현재 해결 방식과 한계: 부서원이 메일·메신저로 근태를 보내고, 검토 담당자가 엑셀에 옮겨 직접 분류·계산한다. 수합, 수작업 계산, 기준 변경 시 재계산이 번거롭다.

## 3. 기능 요구사항

- 평가기준(조원이 알려 준 내용 그대로)
  - 부서 충족: 부서원 전체인원 중 평가대상자의 50% 이상이 개별 실적을 달성해야 한다.
  - 개별 실적 달성: 금요일 8시간 근무 중 4시간 이상의 부재(휴가, 출장)가 되었을 때 달성이다.
  - 평가대상자: 전체인원에서 교육대상자를 제외한다.
- 핵심 기능 (우선순위 순)
  1. 개인 근태 입력 (기능 A, 페이지 `IN`) — 부서원이 목요일 퇴근 전까지 금요일 하루의 부재 유형(없음·휴가·출장)과 부재 시간을 직접 입력한다. [가정] 처음 정한 '근무 유형' 항목을 평가기준에 맞춰 '부재 유형 + 부재 시간'으로 바꿨다. 반차는 휴가 4시간으로 입력한다.
  2. 충족 여부 검토 (기능 B, 페이지 `board`) — 금요일 근태를 위 평가기준에 따라 분류해 개인별 달성 여부와 부서별 충족 여부를 판정한다. 모든 판정은 "담당 검토 후 확정"으로 표시한다.
  3. 미입력자 현황 — 마감까지 입력하지 않은 평가대상자를 한눈에 확인한다. [가정] `board` 페이지에 둔다.
- 다음 단계: 평가기준 설정(기준이 바뀌면 설정만 고쳐 다시 계산), 검수·확정, 메인 요약 강화, 부서원 50명의 실제 수합(JSON 백업 가져오기)
- 차별점: 부서원이 직접 입력해서 메일·메신저로 받아 엑셀에 옮겨 적는 수합 과정이 없어진다.

## 4. 비기능 요구사항

- 사용 환경: 여러 페이지 HTML 웹앱(브라우저, PC 기준), GitHub Pages 배포. 서버·로그인·외부 라이브러리·외부 전송 없음. 페이지끼리 데이터는 localStorage 하나로 주고받는다. 이번에는 검토 담당자 한 사람이 가상 표본으로 입력부터 검토까지 한 화면에서 시연한다.
- 데이터 민감도: 가상 부서명·가상 사번·대상 금요일 날짜·부재 유형·부재 시간·교육대상자 여부. 실명·연락처·실제 자료는 넣지 않고 외부로 보내지 않는다. 모든 판정은 "담당 검토 후 확정".
- 제약: 실습 당일 시간 안에 끝낸다(조 결정).

## 5. 성공 지표

- 성공 모습: 가상 표본을 넣으면 부서별 4.5일제 충족 여부와 마감까지 입력하지 않은 평가대상자가 화면에 바로 보인다.
- 핵심 지표 (같은 비중): ① 충족 여부 판정 — 입력된 근태가 평가기준에 따라 분류되어 부서별 충족 여부가 나온다. ② 미입력자 목록 — 마감까지 입력하지 않은 평가대상자가 목록으로 보인다.
- 성공 시나리오 [가정: 세션이 평가기준에 맞춰 제안, 팀 확인 필요]
  - S1: `IN` 페이지에서 가상 사번을 고르고 부재 유형(휴가)과 부재 시간(4)을 입력해 저장하면 → 시작 페이지 요약의 근태 입력 건수가 1건 늘고, `board` 페이지 개인별 표에 그 사번이 '달성'(부재 4시간)으로 보인다.
  - S2: 표본(부서원 명단 + 금요일 근태)을 시작 페이지에서 가져온 뒤 `board` 페이지를 열면 → 부서별로 "달성자 n / 평가대상자 m"(교육대상자 제외)과 "충족 또는 미충족 (담당 검토 후 확정)"이 보인다. 개인은 부재 4시간 이상이면 달성, 부서는 평가대상자의 50% 이상이 달성이면 충족이다.
  - S3: 같은 표본으로 `board` 페이지를 열면 → 근태를 입력하지 않은 평가대상자가 미입력자 목록으로 보인다. 교육대상자는 평가대상자가 아니므로 목록에 나오지 않는다.
  - S4: 같은 사번이 같은 금요일에 두 번 들어 있는 표본(일부러 넣은 함정)을 가져오면 → `board` 페이지에 그 사번이 "확인 필요 — 중복 입력"으로 사유와 함께 따로 보이고, 달성 판정과 미입력자 목록에는 들어가지 않는다.
