제목: [기능] 기능 A — 근태 입력 페이지(IN)

## 목적

- 제목 규칙: `[기능]` 근태 입력 페이지
- 요구사항: `docs/team_plan.md` R1 — 부서원이 대상 금요일의 부재 유형(없음·휴가·출장)과 부재 시간을 입력해 저장한다.

## 완료 기준

- ☐ 성공(S1): `IN`에서 가상 사번을 고르고 휴가 4시간을 저장하면 `attendance`에 1건이 저장되고, 시작 페이지 근태 입력 건수가 1건 는다.
- ☐ 실패할 때: 사번 미선택, 부재 시간 0~8 밖, 부재 유형 '없음'인데 시간이 0이 아닌 입력은 저장하지 않고 어느 칸이 틀렸는지 알려 준다. 명단이 비어 있으면 "시작 페이지에서 표본을 먼저 가져오세요"를 보여 준다.
- ☐ 경계: 부재 0시간·4시간·8시간이 저장된다. 같은 사번·같은 날짜를 다시 저장하면 기존 건을 고치고 건수가 늘지 않는다.
- ☐ 저장은 `common.js`의 `loadData`·`saveData`로만 하고, `attendance` 외의 칸은 바꾸지 않는다.
- ☐ `tests/acceptance.md`의 AC1·AC5 통과
