## 1. 요구사항과 완료 기준

| ID | 요구사항 (PRD 3절) | 성공 시나리오 (PRD 5절 S 번호) | 실패할 때 동작 | 경계 조건 |
|---|---|---|---|---|
| R1 | 개인 근태 입력 — 부서원이 대상 금요일의 부재 유형(없음·휴가·출장)과 부재 시간을 입력해 저장한다 (`IN`) | S1 — `IN`에서 사번을 고르고 휴가 4시간을 저장하면 → 시작 페이지 근태 입력 건수가 1건 늘고, `board` 개인별 표에 그 사번이 '달성'으로 보인다 | 사번을 고르지 않았거나, 부재 시간이 0~8 밖이거나, 부재 유형 '없음'인데 시간이 0이 아니면 저장하지 않고 어느 칸이 틀렸는지 알려 준다. 명단이 비어 있으면 "시작 페이지에서 표본을 먼저 가져오세요"를 보여 준다 [가정] | 부재 0시간·4시간·8시간, 같은 사번·같은 날짜를 다시 저장(기존 건 수정) |
| R2 | 충족 여부 검토 — 평가기준에 따라 개인 달성과 부서 충족을 판정한다 (`board`) | S2 — 표본을 가져와 `board`를 열면 → 부서별 "달성자 n / 평가대상자 m"과 "충족 또는 미충족 (담당 검토 후 확정)"이 보인다. S4 — 중복 입력된 사번은 "확인 필요 — 중복 입력"으로 따로 보이고 판정에서 빠진다 | 명단이 비어 있으면 판정 대신 "시작 페이지에서 표본을 먼저 가져오세요"를 보여 준다. 평가대상자가 0명인 부서는 "평가대상자 없음"으로 보이고 판정하지 않는다 [가정] | 부재 정확히 4시간(달성), 달성 비율 정확히 50%(충족), 교육대상자 제외, 휴가·출장이 아닌 '없음' 유형 |
| R3 | 미입력자 현황 — 근태를 입력하지 않은 평가대상자를 보여 준다 (`board`) [가정] | S3 — 같은 표본으로 `board`를 열면 → 입력하지 않은 평가대상자가 미입력자 목록으로 보인다 | 명단이 비어 있으면 R2와 같은 안내. 모두 입력했으면 "미입력자 없음" | 교육대상자는 입력하지 않아도 목록에 나오지 않음, 중복 입력 사번은 목록에 넣지 않음 |
| R4 | 보강 — 걸러 보기·요약 막대그래프·가상 표본 채우기·교육대상자 입력 (PRD 3절 보강 기능 4~7) | S5 — 충족 현황에서 부서·손볼 사람만 걸러 보면 → 해당 부서원만 보인다. S6 — 충족 현황을 열면 → 부서별 달성 비율 막대와 50% 점선. S7 — 시작 페이지 "가상 표본 채우기" → 표본 파일과 같은 자료. S8 — 근태 입력에서 교육대상자를 체크해 저장하면 → 그 부서원이 평가대상자에서 빠진다 | 조건에 맞는 사람이 없으면 "조건에 맞는 부서원이 없습니다." 자료가 없으면 표본을 먼저 가져오라는 안내. 이미 자료가 있으면 표본으로 바꿀지 한 번 더 묻고 취소하면 그대로 | 평가대상자가 0명인 부서(막대 대신 "평가대상자 없음"), 교육대상자 체크를 풀면 원래대로 |
