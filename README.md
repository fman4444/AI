## 1. 무엇을 하는 도구인가

- 해결하는 업무 불편: 매주 부서별로 4.5일제 평가기준 충족 여부를 검토할 때, 근태를 제각각 받아 모으고 평가기준에 대조해 손으로 계산하는 일이 번거롭다.
- 주 사용자: 부서원(근태 입력)과 검토 담당자(충족 여부 검토)
- 들어 있는 검증 절차: 계산 검산(부서별 달성자·평가대상자·충족 판정을 표본을 직접 센 기대값과 대조) · 정합 검사(시작 페이지 요약 숫자 = 충족 현황 숫자, 중복 입력·명단에 없는 사번·값 오류는 '확인 필요'로 따로 표시)
- 출발점: 주 4.5일제 근무에 대한 평가기준이 있고, 매주 부서별로 그 기준을 충족했는지 검토해야 하는 번거로움을 개선하고자 함

## 2. 사용법

1. 배포는 하지 않았습니다(조 결정). 팀 레포에서 **Code → Download ZIP** → 압축을 풀고 `tools/index.html`을 더블클릭합니다.
2. 페이지 목록: 시작(`tools/index.html`) · 근태 입력(`tools/pages/IN.html`) · 충족 현황(`tools/pages/board.html`)
3. 시작 페이지에서 **가상 표본 채우기(시연용)** 버튼을 누르거나 '가져오기'로 `data/team_sample.json`을 불러옵니다. 근태 입력에서 사번·부재 유형·부재 시간을 저장하면, 충족 현황에서 부서별 달성 비율 막대그래프·충족 여부, 미입력자·확인 필요(탭), 개인별 현황이 보입니다. 개인별 현황은 부서별로, 또는 손볼 사람(미달성·미입력·확인 필요)만 걸러 볼 수 있습니다. 근태 입력에서 "교육대상자"를 체크해 저장하면 그 부서원은 평가대상자(모수)에서 빠집니다. 함정 없는 정상 표본 `data/가상표본2(정상).json`(부서원 25명)도 '가져오기'로 쓸 수 있습니다.
4. 평가기준: 휴가·출장 부재 4시간 이상이면 개인 달성, 평가대상자(교육대상자 제외)의 50% 이상이 달성하면 부서 충족입니다. 모든 판정은 "담당 검토 후 확정"입니다.
5. 처음부터 다시 쓰려면 시작 페이지 '비우기'. 데이터는 이 브라우저 안에만 저장되고, 백업은 JSON 파일로 내보냅니다.
6. 화면은 LH 홈페이지 캡처를 참고해 색·구조만 맞췄습니다(`docs/design.md` 5절). 로고 대신 "LH 실습용 · 가상 자료" 표시를 달았습니다.

## 6. 보안과 판단 경계

- 시험에 쓴 데이터는 모두 가상 자료입니다. 실명·연락처·실제 사업 자료가 없습니다.
- 데이터를 외부로 보내지 않습니다. 배포는 하지 않았고, 화면에도 가상 자료만 있습니다.
- 이 도구는 개인 실적 달성과 부서 충족 판정을 확정하지 않습니다. 모든 판정은 "담당 검토 후 확정"으로 표시되고, 결과는 담당자가 확인합니다.
